# Träningsstudion Pulse

Träningsstudion Pulse är en enkel webbplats för ett gym.
Webbplatsen hjälper besökare att hitta information om gymmet och välja ett medlemskap.

## Webbplatsens sidor

- **Hem:** Välkomnar besökaren och visar en knapp för bokning.
- **Boka:** Besökaren kan boka olika träningspass, till exempel yoga, zumba och simning.
- **Schema:** Visar gymmets öppettider och veckans träningspass.
- **Medlemskap:** Visar tre medlemskap: bas, premium och VIP.
- **Kontakt:** Besökaren kan hitta telefonnummer och e-post samt skicka ett meddelande.

## Teknik

Projektet är byggt med:

- HTML för sidornas innehåll
- CSS för färger, layout och design
- Bilder och logotyp i mappen `assets`

Målet med projektet är att skapa en tydlig och lättanvänd webbplats för personer som vill börja träna eller hitta ett gym.
